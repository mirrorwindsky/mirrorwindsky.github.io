## 整体射击逻辑观察

NIKKE中，角色的基础状态有三种：待机（在掩体后无动作）、瞄准射击（出掩体，执行瞄准射击动作）、换弹（在掩体后执行换弹动作）。

其状态切换如下：

```text
               按住鼠标左键攻击
        ┌──────────────────────────┐
        │                          ↓
   ┌─────────┐               ┌─────────────┐
   │  待机   │               │  瞄准 / 射击 │
   └─────────┘               └─────────────┘
        ↑                     │           │
        │                     │           │ 松开且不满弹
        │      松开且满弹      │           │
        └─────────────────────┘           │  或
                                          │
                                          │ 弹药耗尽
                                          ↓
                                   ┌─────────────┐
                                   │    换弹     │
                                   └─────────────┘
                                     │         │
                                     │         │ 未完成换弹动画时
                      换弹动画完成    │         │ 按住攻击
                                     │         │ 且 弹药不为0
                                     ↓         ↓
                                  待机      瞄准 / 射击
```

这部分逻辑比较简单明了，正如上图所示。

真正复杂有趣的其实是“瞄准/射击”这部分的内部具体逻辑。

## 瞄准与射击的基本逻辑

在这部分，按照武器种类不同，有着不同的逻辑。

具体可以分为两类：连射武器（步枪、机枪、冲锋枪、霰弹枪）和蓄力武器（狙击枪、发射器）

对于连射武器，其逻辑为：按住左键开始瞄准，当准星对准到目标上时，就会开始连续射击，直到弹药耗尽强制进入换弹，或松开左键，回到**换弹**或**换弹并待机**

```text
                 按住左键
                     │
                     ↓
              ┌────────────┐
              │    瞄准    │
              └────────────┘
                │        │
      准星命中目标        │ 准星未命中目标
                │        │
                ↓        │
          ┌──────────┐   │
          │ 连续射击 │←──┘
          └──────────┘
            │       │
            │       │ 目标离开准星
            │       └────────→ 瞄准
            │
     ┌──────┴──────────────┐
     │                     │
 弹药耗尽                松开左键
     │                     │
     ↓                     ↓
  强制换弹            松开后处理
                           │
                           ↓
                         换弹
                           │
                       换弹完成
                           ↓
                          待机
```

对于蓄力武器，其逻辑为：按住左键开始瞄准并蓄力（积累蓄力条），直到松开左键后才射击一发，并且无论是否瞄准到目标上都会射击，蓄力条也不需要满载，只要松开了左键就会射出这一发，这后就回到正常松开后逻辑，回到**换弹**或**换弹并待机**

```text
                 按住左键
                     │
                     ↓
             ┌─────────────┐
             │  瞄准 + 蓄力 │
             └─────────────┘
                     │
              持续按住左键
                     │
                     ↓
                蓄力条增长
                     │
                     │
                 松开左键
                     ↓
             ┌─────────────┐
             │   射击一发   │
             └─────────────┘
                     │
                     ↓
                松开后处理
                     │
                     ↓
                   换弹
                     │
                 换弹完成
                     ↓
                    待机
```

可以推测，假设**瞄准/射击**这一状态下，可能采用了类似AimFire(ContinuousFire)（持续射击）和AimFire(ChargeFire)（蓄力射击）两种调用，并依据武器类型来判断条件。

## 特殊情况：多种特殊射击方式

如果只看上面的普通武器，那么按照武器类型，在ContinuousFire和ChargeFire两种逻辑之间选择就已经足够。

但实际游戏中还存在一些特殊角色，会改变原本的射击方式。

最明显的例子是狙击枪角色“小红帽”。正常情况下，她和其他狙击枪一样，需要按住左键进行蓄力，松开后射击一发。但在开启技能后，她会直接变为连射模式。此时虽然角色使用的仍然是狙击枪，但操作方式已经变成按住左键持续射击。

也就是说，单纯通过武器类型来决定射击逻辑，在这里就会出现问题。

一种比较简单的处理方式，是给角色一个**默认射击模式**，同时允许技能临时覆盖这个模式。例如：

```text
DefaultFireMode = ChargeFire

技能开启：
CurrentFireMode = ContinuousFire

技能结束：
CurrentFireMode = DefaultFireMode
```

调用时可能类似：

```text
fireMode = GetCurrentFireMode()

AimFire(fireMode)
```

其中GetCurrentFireMode()默认根据武器配置返回射击方式，如果当前有技能或特殊状态，则优先返回被修改后的射击方式。

除了这种直接切换射击方式的情况，一些特殊发射器还有另一套逻辑。

这类角色在按住左键之后仍然首先进行蓄力，但当蓄力条达到满值以后，只要玩家继续按住左键，就会直接开始连续射击，不需要像普通发射器一样每一发都松开一次。

其状态大致可以表示为：

```text
                 按住左键
                     │
                     ↓
              ┌────────────┐
              │    蓄力    │
              └────────────┘
                     │
                蓄力未满
                     │
                     └──────→ 继续蓄力
                     │
                 蓄力完成
                     ↓
              ┌────────────┐
              │  连续射击  │
              └────────────┘
                     │
                 持续按住
                     │
                     └──────→ 连续射击
                     │
                  松开左键
                     ↓
                 松开后处理
```

如果玩家在蓄力完成后松开左键，再次开始攻击时则需要重新蓄力，不能直接进入连射。

因此这一类可以单独看作另一种射击模式，例如：ChargeContinuousFire

那么AimFire()内部实际可以不只有前面的两种模式，而是类似

```text
AimFire(ContinuousFire)

AimFire(ChargeFire)

AimFire(ChargeContinuousFire)
```

普通情况下，射击方式可以由武器类型决定；遇到特殊角色或技能时，再通过角色配置、技能状态等方式修改当前的射击模式。

这样处理以后，前面最外层的 待机 → 瞄准/射击 → 换弹 状态不需要跟着变化。特殊角色主要修改的是 瞄准/射击 状态内部具体如何触发射击。

以后如果再出现**新的特殊射击方式**，也只需要继续增加新的FireMode开火模式，处理这一种射击方式自己的逻辑，外层状态机基本不用改。
